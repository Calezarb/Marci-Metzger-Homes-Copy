# Marci Metzger Homes Copy

A static real-estate landing page for Marci Metzger / The Ridge Realty Group, built with HTML, CSS, and JavaScript.

## Project Overview
This project is a front-end mockup for a luxury real estate website focused on Pahrump and surrounding Nevada markets. It includes a hero section, about section, sales section, search form, and supporting styling/animations.

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Files
- `index.html` – main page structure
- `css/style.css` – styling and responsive layout
- `js/script.js` – interactions and UI behavior
- `images/` – project assets and icons

## Local Preview
Open `index.html` in a browser, or run a local static server from the project folder.
